### About Me

I am a Ph.D. student working on **AI for Games**, with a focus on **AIGC tools for game art production**, **LLM/VLM agents**, and **generative game engines**.

My current direction is to turn generative AI from research demos into practical tools for game production workflows: editable game UI generation, game art asset assistance, VLM-based evaluation, and hardware-aware neural rendering.

I am currently interning in the **Machine Learning Group at Tencent TiMi Studio J1**, working on **AI-assisted game art asset production**.

Before my Ph.D., I worked as a **GPU systems algorithm engineer**, deploying and optimizing AIGC models such as Stable Diffusion on domestic GPU chips. This gives me a cross-layer view from model design to inference systems and production tooling.
